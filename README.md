# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/9b7cf0af-76e4-4607-8793-ac4d1e245c49

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Copy [.env.example](.env.example) to `.env` and fill in the Firebase, Resend, admin registration, and password hashing values.
3. Run the app:
   `npm run dev`
